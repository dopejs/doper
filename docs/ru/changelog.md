# Changelog

Политика версий описана в `docs/release.md`: 11 пакетов публикуются атомарно с одной и той же версией,
а semver в npm и версия бинарного ABI управляются независимо.

## Unreleased

- Начиная со следующей версии npm лицензия проекта меняется с MIT на Apache-2.0;
  опубликованные версии до v0.2.1 включительно остаются под лицензией MIT.
- Кривая передачи колеса выровнена с браузерной: дискретные щелчки колеса прокручиваются анимацией, а
  дельты высокой точности (трекпад) по-прежнему применяются 1:1 сразу. В `DispatchEvent` потока ввода
  добавлено поле флагов, версия ABI выросла с 1 до 2.
- Официальный сайт доступен на упрощённом китайском, традиционном китайском, испанском, французском,
  немецком, русском, иврите, арабском, японском и корейском.

## 0.1.0

Первый публикуемый выпуск. Все инженерные вехи P0–M5 завершены, `pnpm m5:check` (полная автоматическая
цепочка от M0 до M5) полностью зелёная.

- Детерминированное ядро на Rust/WASM + оболочка на TypeScript: схема с единственным источником,
  версионированные бинарные потоки Mutation/Input/DisplayList и обратный поток, атомарное отклонение
  некорректного ввода.
- Рендеринг с двумя тактовыми осями: цепочка SAB → postMessage → Canvas2D в главном потоке; Worker
  продолжает выводить кадры даже при блокировке главного потока на 200 мс.
- Нативная виртуальная прокрутка (воспроизведение с P95/P99 меньше микросекунды на миллионе строк) и
  текстовая подсистема (явный шейпинг шрифтов, атлас глифов, откат к системным шрифтам).
- Нативное редактирование в canvas: два пути через EditContext и прокси ввода, композиция IME,
  навигация каретки указателем и клавиатурой, буфер обмена, undo/redo, маскирование паролей и
  scroll-into-view для каретки.
- Hit-тестирование (инкрементальный BVH и property-тесты против наивного оракула) и трёхфазные события
  перехват/цель/всплытие, протокол синхронного `preventDefault` для непассивных областей.
- Доступность: экспорт дерева семантики, зеркалирование в теневое DOM-дерево, семантические E2E-селекторы
  `getByRole`, перенаправление клавиатурного фокуса.
- Миграция и вывод в продакшен: `@dopejs/pingo-compat` для постраничного раскатывания и возврата, сканер
  миграции, проверка целостности пакета и WASM по SHA-256, диагностика и операционное руководство.
- Изолированный прототип WebGPU и сравнение без расхождений с headless-оракулом (ADR-0006:
  Continue Experiment, по умолчанию выключено).

Явно отложено: визуальная навигация в bidi, placeholder в виджетах, включение WebGPU по умолчанию.
Квалификация платформы (производительность на реальных устройствах, настоящие IME, программы чтения с
экрана) отслеживается отдельно и не обещается версией пакета.
