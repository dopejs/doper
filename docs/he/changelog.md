# Changelog

מדיניות הגרסאות מתוארת ב-`docs/release.md`: עשר החבילות מתפרסמות אטומית באותה גרסה, ו-semver של npm
וגרסת ה-ABI הבינארי מנוהלות בנפרד.

## Unreleased

- עקומת ההעברה של הגלגלת יושרה להתנהגות הדפדפן: נקישות גלגלת בדידות נגללות באנימציה, ואילו דלתות
  ברזולוציה גבוהה (משטח מגע) ממשיכות להיות מיושמות 1:1 מיד. ל-`DispatchEvent` בזרם הקלט נוסף שדה דגלים,
  וגרסת ה-ABI עלתה מ-1 ל-2.
- האתר הרשמי זמין בסינית מפושטת, סינית מסורתית, ספרדית, צרפתית, גרמנית, רוסית, עברית, ערבית, יפנית
  וקוריאנית.

## 0.1.0

הגרסה הראשונה הניתנת לפרסום. כל אבני הדרך ההנדסיות P0–M5 הושלמו, ו-`pnpm m5:check` (שרשרת השערים
האוטומטית מ-M0 עד M5) ירוקה במלואה.

- ליבת Rust/WASM דטרמיניסטית ומעטפת TypeScript: סכימה בעלת מקור יחיד, זרמים בינאריים עם גרסאות
  (Mutation, Input, DisplayList והזרם ההפוך), ודחייה אטומית של קלט פגום.
- רינדור בשני שעונים: שרשרת SAB ← postMessage ← Canvas2D בתהליכון הראשי; ה-Worker ממשיך להציג גם
  כשהתהליכון הראשי חסום 200 מילישניות.
- גלילה וירטואלית נייטיב (הרצה חוזרת עם P95/P99 מתחת למיקרו-שנייה על מיליון שורות) ותת-מערכת טקסט
  (עיצוב גופנים מפורש, אטלס גליפים, נסיגה לגופני מערכת).
- עריכה נייטיב ב-canvas: שני נתיבים דרך EditContext ומתווך הקלט, הרכבת IME, ניווט סמן במצביע ובמקלדת,
  לוח גזירים, ביטול/ביצוע חוזר, מיסוך סיסמאות וגלילת הסמן לתוך התצוגה.
- בדיקת פגיעה (BVH מצטבר ובדיקות תכונה מול אורקל נאיבי) ואירועים בשלושה שלבים (לכידה, יעד, בעבוע), עם
  פרוטוקול `preventDefault` סינכרוני לאזורים לא פסיביים.
- נגישות: ייצוא העץ הסמנטי, שיקוף לעץ DOM צללי, בוררי E2E סמנטיים באמצעות `getByRole` והעברת מיקוד
  מקלדת.
- הגירה והפעלה בייצור: `@dopejs/doper-compat` להשקה ולחזרה לפי עמוד, סורק הגירה, אימות שלמות החבילה
  וקובץ ה-WASM ב-SHA-256, אבחון וספר הפעלה.
- אב-טיפוס WebGPU מבודד והשוואה ללא פערים מול האורקל חסר הממשק (ADR-0006: המשך ניסוי, כבוי כברירת מחדל).

נדחו במפורש: ניווט חזותי בטקסט דו-כיווני, מציין מקום ברכיבים המוכנים והפעלת WebGPU כברירת מחדל.
הסמכת הפלטפורמה (ביצועים במכשירים אמיתיים, שיטות קלט אמיתיות, קוראי מסך) נמדדת בנפרד ואינה מובטחת עם
גרסת החבילה.
