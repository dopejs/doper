# Pingo brand assets

`pingo` comes from Latin `pingō`: to draw, paint, or depict.

The mark is deliberately monochrome: an open rounded ring is the canvas in progress, and the isolated dot is the current paint point. Color is not required for recognition.

- `pingo-mark.svg`: transparent primary mark
- `pingo-mark-mono.svg`: `currentColor` version for inline SVG
- `pingo-icon.svg`: dark rounded app tile
- `pingo-favicon.svg`: simplified small-size icon

Keep the opening and dot in the upper-right position. Do not rotate, stretch, outline, or add a shadow.
